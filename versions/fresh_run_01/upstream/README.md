# Franka Robotics Cobot Pump

FR3 Cobot Pump MJCF and unmodified collision/visual STL from [MuJoCo Menagerie PR 239](https://github.com/google-deepmind/mujoco_menagerie/pull/239), pinned to [the contributor’s commit](https://github.com/rpapallas/mujoco_menagerie/tree/6eec4ec3913d816669c8e3b9827656c850000edd/franka_fr3_v2). This is an open PR. The original XML references other FR3 meshes. The B+C loader extracts only the pump inertial element and uses the pump mesh. Source model license is included in LICENSE.

The STL is byte-identical to the [official Franka collision asset](https://github.com/frankarobotics/franka_description/blob/7aeeddc449edf8d62b594f9e36a81da53e7796f9/meshes/robot_ee/cobot_pump/collision/cobot_pump.stl). The SHA-256 digest is a00f8acc46fa2e1746a7543c3e964a01dc47c9c1fc941099f6cdb05472249db8. LICENSE.franka and NOTICE are from that commit. The [manufacturer](https://franka.de/cobot-pump) identifies it as Cobot Pump, sold by Franka Robotics and developed with Schmalz. The official [Franka documentation index](https://franka.de/documents) links the Schmalz [ECBPi CobotPump operating instructions](https://download.franka.de/documents/221010_Operating%20Instructions%20ECBPi%20CobotPump_11.18_EN.pdf). Section 4 identifies ECBPi 12. Section 11.2 lists both SPF 30 ED-65 G1/8-AG and SPB1 30 ED-65 G1/8-AG accessories. The mesh metadata does not uniquely identify the replaceable cup’s order number.

For the Kinova mount we replace the FR3 attachment and derive collision hulls by clipping the supplied mesh along its axis. We use its supplied full-size STL for rendering, 34 mm coaxial simulation adapter with a recessed stem and 62 mm face flange, segmented seal ring fitted to its terminal rim, and force-limited contact coupling. Original inertial mass 1.01 kg from the MJCF is retained. The product page quotes 810 g for the product. The original author’s 40 N adhesion actuator and upstream z=100 mm site are replaced. The mesh rim terminates at z=109.013 mm, radius 13.96 mm. The upper pressure specification is 75 kPa. Operating pressure 70 kPa, effective radius 12.5 mm and shear/peel/twist coefficients are simulation assumptions. Neither the adapter nor the simulated seal has been physically qualified.
